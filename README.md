# React + Vite

## 🚀 O gerador de Prompt AI

Um gerador de prompts inteligentes projetado para transformar ideias simples e pouco estruturadas em prompts robustos e eficientes para uso com Inteligência Artificial.

## 📌 Sobre o Projeto

O Gerador de Promt AI nasceu de uma necessidade comum: criar prompts melhores sem precisar dominar técnicas avançadas de engenharia de prompts.

A proposta inicial é simples:

Receber entradas básicas (até mesmo vagas ou mal estruturadas)
Transformá-las em prompts claros, objetivos e eficazes
Evoluir progressivamente com recursos mais avançados



## 🎯 Objetivo

Facilitar o uso de IA para qualquer pessoa — especialmente desenvolvedores iniciantes — reduzindo a barreira de criação de prompts eficientes.

⚙️ Funcionalidades (MVP)
✏️ Entrada de prompt simples (texto livre)
🧠 Estruturação automática baseada em boas práticas
📦 Geração de prompt com formato padrão:
Contexto
Tarefa
Formato de saída
Exemplos (quando aplicável)
Exemplo

Entrada do usuário:

quero aprender javascript

Saída gerada:

Contexto: Você é um professor de JavaScript para iniciantes
Tarefa: Ensinar os conceitos básicos de JavaScript
Formato: Explicação com exemplos práticos e exercícios simples
